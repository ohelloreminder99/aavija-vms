# Gatekeeper Dashboard Architecture (Mobile)

The Gatekeeper dashboard is the high-security interface for security personnel at the entry/exit points of a Premise.

## 1. Scanning Interface (`ScannerScreen`)
- **QR Scanner:** Uses the device camera to decode symbols generated by Visitors or Owners.
- **Logic Service:** `QrVerificationService`.
- **Verification Flow:**
    1. **Decryption:** Decodes the scanned token.
    2. **Lookup:** Validates existence in `users` (for identity) or `premises` (for linking).
    3. **History Check:** Ensures the visitor isn't already checked-in elsewhere (Conflict Prevention).
    4. **DND/Blacklist:** Checks if the visitor is blocked by the Owner.

## 2. Check-in Confirmation Workflow
- **Visitor Profile Card:** Displays the scanned visitor's Image, Name, and Phone.
- **Vehicle Matcher:** Compares the actual vehicle plate with the visitor's `selected_vehicle_number`.
- **Host Selection:** Logic allowing Gatekeeper to link the visit to a specific Host (Tenant/Employee) within the premise.
- **Confirmation Action:** Calls `rpc_confirm_checkin`.
- **System Effect:**
    1. Creates a new row in `visits` table with status 'active'.
    2. Updates `users.active_checkin_id` for the visitor.
    3. Triggers real-time notification to the Host/Owner.

## 3. Checkout Verification Flow
- **Detection:** If the scanned visitor's `active_checkin_id` is present, the scanner automatically presents a "Confirm Check-out" button.
- **Verification:** Gatekeeper confirms the visitor is indeed exiting the premise.
- **Action:** Calls `VisitCheckoutService.checkoutVisitor` with `gatekeeper_id`.
- **System Effect:** 
    1. Sets `checkout_time` and status to 'completed' in `visits` table.
    2. Nullifies `users.active_checkin_id`.
    3. Audit Link: Description includes `"Verified by gatekeeper [ID]"`.

## 4. History & Audit
- **Daily Log:** Displays a list of recent check-ins for the current gatekeeper's session.
- **Quick Search:** For looking up visitor names/vehicle numbers in the local daily list.

## 4. Security Settings
- **Change Password:** Basic auth management (Supabase Auth).
- **Shift Handover:** (Inferred Logic) Clearing local session state when shift ends.
